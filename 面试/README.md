# 项目讲解与面试材料

本目录是项目面试、答辩和对外讲解材料的唯一入口。原 `docs/interview/` 已合并到这里。任务台账、逆向证据和架构合同仍保留在各自的权威目录；这里负责组织讲法，不替代项目事实来源。

当前状态基线为 2026-08-24。讲述前若项目继续推进，应优先复核任务台账，而不是机械沿用本文中的数字。

## 一套完整讲法

1. 先用 `Harness工程.md` 或 `游戏项目.md` 的 30 秒概述说明项目价值和本人职责。
2. 用 `项目最大挑战.md` 讲清楚“从不完整遗留资料恢复可验证事实”这一主线，再按岗位选择 Agent Harness、双玩家数据所有权、原子事务、UI 原生化或关卡/怪物架构作为第二案例。
3. 用 `设计模式.md` 解释现代代码为什么这样拆，而不是只说“做了重构”。
4. 用 `逆向技术讲解.md` 说明结论如何从不完整资料中被证明。
5. 回到主稿的“不应过度声称”与常见追问，主动区分已确认事实、工程集成和仍在演进的部分。
