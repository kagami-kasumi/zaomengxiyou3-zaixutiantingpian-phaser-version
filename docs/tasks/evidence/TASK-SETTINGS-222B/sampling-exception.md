# 222B 有限采样近似裁决

2026-09-16 用户针对本任务询问明确回复：**“接受这 70 个像素的有限近似”**。

许可仅覆盖 `residual-cases.json` 列明的 20 个原生输入案例、70 个二值命中像素：`PetTurtle1Bullet2` 自由播放 tick 19、镜像方向、scale1、目标0/1、双方 phase1..5。完整 94,656 个静态案例的命中布尔值无差异；另 31,344 个真实动态调用案例的命中布尔值与 109,371,992 个像素均无差异。

原版 `HitTest` 的输出仍是精确 oracle；源绘制场采样器在这份有限输入上的差异属于获准的现代采样近似，不改写为原版事实或通用 AIR 等价。批准不扩展到其他坐标、方向、相位、缩放、目标、宠物或未来算法。后续实现必须直接消费该原生输入集及精确残差白名单；新增残差或任何命中布尔差异均失败，不以总像素数阈值放行。

诊断记录：早期单幅场有919像素残差；补入独立目标覆盖场后剩74；局部分块场通过完整相位验收后剩上述70。对同一源树改变整数绘制原点可改变少量栅格像素，不能把整张图平移后当作完全等价。加密相位和增加分块边距未消除最终残差，保留实验记录，不删除反证。
