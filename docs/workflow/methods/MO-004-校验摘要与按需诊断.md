# MO-004 校验摘要与按需诊断

状态：已归档。

提出者/来源：2026-10-02 用户要求；[PG-019](../problems/PG-019-校验结果模型读取成本缺少约束.md)。

最迟复核点：后续第三个真实适用批次结束，或 2026-10-16 起首次执行相关工作的收尾，先到者裁决。无自动后台监控、不为到期单独启动任务。

## 1. 方法与假设

S1：命令 stdout/stderr 完整落入既有本地证据目录或 `.tmp/`；模型先看命令、范围、退出码、重要告警/跳过和日志位置。成功时不导入逐测试/逐态明细。假设减少无用输入和重复解释。

S2：自然失败时先提取错误标识、首个相关堆栈及必要上下文，再按未解决问题扩展；多种独立失败需分别列明，禁止只保留首错而隐藏其余错误。假设减少定位前的大段日志阅读。

S3：依照现有协议复用同批相同相关输入的结果，核对测试代码、被测实现、资源/真值和必要环境未变；输入无法确认、旧失败未解决或运行未结束时不得复用。只引用原结果，不再重复分析。不建立跨任务永久免检。

本试验不优化测试运行时间，不缩减断言、后端、正式旅程或原版独立预期。已有人工视觉要求继续执行。

## 2. 基线与指标

历史校验分项 token 无可靠计量，标记未知。不得以账号额度差、运行时间、测试条数或日志字节数冒充实际 token。

每个样本就地对照，不重新跑基线：B 为该批唯一命令原本会返回的完整日志 Unicode 字符数；I 为实际送入模型的校验输出、追加读取、截图说明和本方法采样材料的文本字符总数（重复读取重复计）。仅对原本直接回传日志的命令计算 I/B；已有摘要的入口单列，不虚构全量读取基线。

- 记录 B、I、I/B、无理由重复读取次数 R，以及新增截图次数；截图内容无法折算字符，不计作零成本。
- 实際 token 若有可靠的本批分项记录可以补充，否则统一写未知；I/B 只表示相对于完整日志回传的输入代理量，不能表示历史实际 token 节省率。
- 质量护栏：隐藏失败/重要 warning/覆盖限制、错误复用、漏掉必需验收均为 0；人工视觉检查完成情况单列。
- 记录取数、读方法和写样本的额外开销，避免观测本身变成更大成本。无需读取完整会话、安装 tokenizer 或创建自动遥测。

## 3. 试验设计

- 后续三个本来需要执行校验的真实批次，每批最多一条集中记录；本次建立规则不计样本。
- 至少两个含较长自动日志的成功批次，覆盖至少两类命令（如系统/浏览器测试、构建/工程检查）。自然失败若出现计入 S2；不故意制造失败凑样本。
- 完整日志仅本地保存，不提交逐态证据。摘要尽量紧凑，既有结构化报告优先；未知格式先窄读确认，不能仅凭末尾 passed 字样判绿。
- 取数可由 shell 计算日志和已保存摘要字符长度；追加诊断计入 I。不能可靠取得则该项未知，该样本只能证明可行性，不用于效率达标。
- 三批或期限到达必须裁决；类型/指标不足就缩小采纳范围或修订/停止，不无限续期。没有自然失败时 S2 维持候选、退出本轮有效性声明。
- 任一质量护栏反例立即停止有问题的策略，PG 转复盘；连续两批净输入代理量不降且无质量收益时提前修订。

## 4. 采纳标准

- 采纳 S1/S3：三个有效样本、满足上述类型要求；可比样本 I/B 中位数不高于 30%，R=0，没有新增非必需截图、误判或漏项。30% 是试验目标，不是已达收益，不要求抑制必要诊断。
- S2 只有自然失败且完整解决并验证后才能判可行；单个失败不证明普遍有效。证据不足不连带否定 S1/S3。
- 修订：指标不足、原本已有摘要导致对照不成立、取数成本超过收益或必要诊断被妨碍；保留失败样本，明确新边界。
- 停止：靠漏验收/删断言获得节省，或无法形成可复查且低成本的效果证据。自动测试照常执行。
