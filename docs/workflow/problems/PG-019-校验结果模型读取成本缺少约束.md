# PG-019 校验结果模型读取成本缺少约束

状态：复盘中。

来源：2026-10-02 用户明确要求只治理校验部分的 token 消耗，并观察方案效果；关联 [MO-004](../methods/MO-004-校验摘要与按需诊断.md)。

## 1. 问题定义

自动测试条数不等于模型 token 用量。校验日志、逐态证据和重复结果进入模型上下文，以及由此产生的重复分析，才是本问题治理对象。现有命令分层、同批去重和结果复用已有规定，但缺少结果读取的试行方式和效果量度，无法回答校验 token 有多少浪费。

范围仅含选择必要校验、执行反馈、读取结果、失败诊断和验收汇总。普通开发/逆向阅读、整体上下文治理、机器运行时间、模型选择不计入效果指标。不得以本项为由删除正确性断言、减少合同覆盖、取消人工必需视觉验收或切换 Canvas/WebGL。

## 2. 证据

- `tools/pet-passive-render.mjs` 自动遍历双后端并保存完整报告；65,280 态不是模型逐态判断。`docs/reverse-engineering/pet-passive-display-acceptance.md` 记录全量、正式旅程和失败重跑，未记录校验专属模型用量。
- `tools/check-system-design.mjs`、`tools/system-test-suites.mjs` 已用 Set 去重；`code-quality-gates.md` 已允许同批相同输入复用。不能把现状写成没有任何减负措施。
- 本次对话核对既有验收时，宽搜索扫入大型证据，工具报告严重截断；这是明确的校验结果查询反例，不代表历史每次校验都如此。未保存可靠分项 token，浪费数量未知，不倒推百分比。

## 3. 解决方案

V1 在 [MO-004](../methods/MO-004-校验摘要与按需诊断.md) 试行三个方案：S1 完整日志本地保存、通过读取简短摘要；S2 失败按错误标识窄读并按需要扩展；S3 同批相关输入未变的已核对结果只引用、不重复分析。执行路由写入 `code-quality-gates.md`，不新增测试框架、永久缓存或强制 token 遥测。

摘要必须保留命令范围、真实退出码、未覆盖/跳过、重要 warning 和证据路径；退出 0 但仅 diagnostic/smoke/iteration 的结果不升级为完整通过。无法判断时展开证据，不为指标硬截断。

V2（2026-10-02，停止V1量化采样）：三个真实批次没有可靠全批B/I，V1不能证明效率标准。保留V1与MO历史证据；不继续要求普通任务统计字符或自动续期。摘要完整性/必要诊断/同批复用仍按code-quality-gates执行。替代量测方案尚未建立，只有明确治理请求或低成本可靠分项指标方案出现时再定向设计与验证；不抢占游戏队列、不声称问题关闭。

## 4. 测试方案

- 本次文档执行 `npm run check:workflow`、`npm run audit:problems` 和 `git diff --check`，检查链接、PG 合同、原质量边界和实际 diff。
- 按 MO-004 收集后续三个真实适用批次，完整日志保留在本地，集中审计只记一次指标与路径。
- 核对摘要与真实退出码/范围/重要告警一致；出现隐藏失败、漏验收或旧结果误复用立即复盘。

## 5. 测试结果

2026-10-02：V1 文档和触发路由已建立，初始化检查结果见 `problem-audit.md` 的同日 PG-019 记录。本批仅为准备/可行性试行，不计后续三个效果样本。尚无可靠分项 token 或真实节省比例；没有删除断言或改动生产渲染后端。

2026-10-02 / 第三批裁决：MO-004停止并归档；249 workflow自然字段失败被识别并修正，但只证明窄诊断可行，全批B/I、R及token不能可靠量测。结论为方案不充分；V2停止自动采样，未满足以下关闭标准，PG不归档。

## 6. 关闭标准

- MO-004 三个真实批次完成并裁决；成功路径达到其效率指标、无质量护栏反例。失败路径若无自然样本，只能保留候选，不宣称已经验证。
- 摘要读取与同批复用稳定规则沉淀到唯一校验协议；正常样本集中记录，无额外重复台账。
- 未量测精确 token 时，只能结论为校验上下文输入量下降，不能宣称整体或精确 token 降幅；有证据的总成本不降则修订/停止，不强行关闭。
- 全部满足后同批归档，保留重开信号：摘要隐藏失败/告警/覆盖限制、复用失效结果、连续两个适用样本净读取量不降且无质量收益。

## 7. 适用触发与反馈记录

触发条件：

- 修改校验输出、汇总或结果复用方式；摘要隐藏失败/告警/范围的反证；用户明确要求成本治理或提出可复查的低成本量测方案。常规读取报告不再触发MO量化采样。

效果检查：

- 保留真实退出码、范围、告警与可定位完整日志；核对结果复用的相关输入。不得用日志长度冒充token，不重新开启已停止的MO量化采样。
- 正常样本只写 `docs/workflow/problem-audit.md`；只有新方案/反证更新本PG。V1已按第三批裁决停止，替代方案及效率关闭证据仍缺。
- 本 PG 不抢占游戏执行队列，方法附着于本来需要的校验；不为了取样重复跑测试。
