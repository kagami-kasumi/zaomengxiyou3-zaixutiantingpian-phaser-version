# 宠物家族碰撞与host相位补充方案

仅适用于task显式指定的单一家族补证；不建立新架构或批量扫描其他家族。保留其既有verified视觉输入与全部行为合同。

1. 冻结显示全集：从指定AS3的真实创建点/继承创建点列body、Special/Follow/EnemyMove、disabled前置和附属buff，映射恢复SWF实际owner/SymbolClass/character及嵌套mask/filter/bitmap。记录源hash，不能仅用主要symbol清单断言全集。
2. 冻结host状态：先body动作游标/hold及回调，再私有bullet.step2、source位移/翻转、伤害/hurt/末帧/超时/死亡/销毁。把action编号、source step和绘制后相位分开；同symbol不同弹体类分别采样。使用原方法/原生时间轴，不能读取现代activeAfterMs生成expected。
3. 提取原显示列表及独立图层：复用已验证body/effect静态像素但重核实际相位和动态变换。源注册点、local/world/root/目标colipse、方向与亚像素来源均落UI Schema兼容机器真值。所有递归状态含不可见/disabled/释放态，不能首帧mask代表全时间轴。
4. 空间oracle：针对task指定正式目标colipse映射，原包AIR执行原HitTest/绘制采样；包括正负接触、离开/进入、空白/透明/遮罩、双方向、实际支持host rate、源移动翻转、目标移位及实际位移相位。原版布尔/像素结果与独立解码/消费实现交叉比较。有限采样边界与不可证明的任意空间外推必须明确。
5. 完整性及反证：核销全部声明对象/状态/方法与行为合同；独立源基准、schema、原生oracle及逐状态对比通过。变异至少拒绝锁定ID免碰撞、首帧mask、错误相位/方向/原点、前置disabled变可伤害、错误source-hurt/末帧销毁与错误owner。负向试验不得覆盖正常证据。
6. 交付：task专属manifest、源基准、oracle、消费者所需相位/坐标转换和未解清单。完整机器真值verified前不解除实现阻塞。不修改src/生产资源/原提取结果；运行必需派生数据由后续实现放正式目录，不能依赖本地证据。仅轻微显示差异可按长期授权如实记录；碰撞/伤害/时序不得继承该容差。
